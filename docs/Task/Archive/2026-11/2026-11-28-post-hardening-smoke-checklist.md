## 结果记录

人工实测（`pnpm tauri:dev`）9/9 通过，未发现功能回归。

实测中出现的两处控制台现象：

1. `Error: Invalid value for <svg> attribute width=""`（Mermaid）
   - 原因：容器不可测量时 mermaid 可能输出空尺寸属性，插入 `innerHTML` 时浏览器报错。
   - 处理：新增 `stripEmptySvgSizeAttrs`，在 4 处 SVG 插入点（预览、PDF 导出、所见 V2、V2 插件）插入前剥掉 `width=""` / `height=""`；空尺寸无语义，不影响布局。
2. `[TAURI] Couldn't find callback id ...`
   - 原因：`tauri:dev` 下 Vite 热更新/刷新会让旧页面的 invoke 回调失效，Rust 完成后找不到回调 id。
   - 处理：仅开发期热重载会出现的预期噪音，发布包不存在该场景，无需修复。若在**没有刷新**的情况下持续刷屏，再单独排查轮询/监听命令。
