## 1. 目标（Goals）

把主题面板里高度重复的「编辑背景」「阅读背景」两块合并为**一个「背景」区**，区内用「界面 / 阅读」分段控件切换目标，**共用同一套控件**；两个背景取值域完整保留。

## 2. 现状分析（Context）

### 2.1 用户诉求与决策

> 「设置中的`编辑背景`和`阅读背景`区域的设置是否可以合并起来？」

评估后给出四个方向，用户选择：**合并成一个「背景」区，用分段控件切换，共用一套控件；两个值都保留；「编辑背景」正名为「界面背景」**。

### 2.2 面板现状（改造前 `src/theme.ts:783-814`）

| 区块 | 控件 |
|------|------|
| 编辑背景 | 9 色板（`data-target="edit"`）、羊皮风格 `#parchment-edit-toggle`、自定义色 `#custom-color-edit` + 应用按钮、**网格背景 `#grid-bg-toggle`** |
| 阅读背景 | 9 色板（`data-target="read"`）、羊皮风格 `#parchment-read-toggle`、自定义色 `#custom-color-read` + 应用按钮 |

两段的色板**完全相同**（`fillSwatches` 用同一份 `buildColorList()` / `buildDarkColorList()` 渲染到所有 `.theme-swatches`），羊皮风格与自定义色输入框也逐字重复 → 视觉冗余、面板偏长。

### 2.3 关键事实：两者作用域不同，不可合成单值

| | `--bg`（编辑背景） | `--preview-bg`（阅读背景） |
|---|---|---|
| 消费点数 | **55 处 / 14 个 CSS 文件** | **7 处 / 3 个 CSS 文件** |
| 覆盖范围 | `body`/`#app`、全部弹窗·对话框·输入框、右键菜单、扩展面板、通知、标签栏、库树、源码编辑区 `.editor`、行号列 `.editor-gutter` | 阅读区 `.preview`、所见容器 `.container.wysiwyg-v2`、所见代码块装饰 |
| 实质语义 | **应用界面色**（外壳） | **纸面色**（内容） |

若强行合成一个值：统一用阅读色 → 所有弹窗/菜单/侧栏变米色；统一用编辑色 → 「阅读背景」设置项消失。此外「网格背景」CSS 是 `.container.edit-grid-bg:not(.wysiwyg-v2)`（仅源码模式生效）、「羊皮风格」是两个独立 class、「纯白背景」特殊处理 `preview-plain` 只读 `readBg` —— 都会语义分裂。

→ **决策：只合并 UI，不合并取值。** 两个值域（含暗色变体）完整保留，键名不变、无数据迁移。

### 2.4 既有机制（合并的可行性依据）

- 色板/自定义色/应用按钮全部通过 `data-target` / `data-for` 在**事件触发时**读取目标 → 切换分段时改写属性即可，无需改动取值分支。
- 面板 DOM 由 `createPanel()` 生成，监听绑定在 `ensureThemePanelReady()`。

## 3. 事实源分层（本次的核心设计）

三层各司其职，杜绝「同一状态存多处」的漂移：

| 层 | 载体 | 职责 |
|----|------|------|
| ① 用户意图 | radio 勾选态 | 用户点了哪一段 |
| ② **生效目标（唯一事实源）** | `.theme-bg-section` 的 `data-bg-target` | 当前这一段是谁 |
| ③ 控件归属（派生） | 各控件的 `data-target` / `data-for` | 事件处理据此写入对应字段 |

切段时**只有 `syncBgControls()` 一个写入点**，控件归属不可能各写各的。

## 8. 关键实现要点

1. **`fillSwatches` 改为原地更新**（D3 修复）：只在色板数量与当前色板不一致时才重建 DOM。这样既修掉「点色板面板自关」，也顺带避免每次点色都重建 10+ 个节点。
2. **`syncBgColorInput` 收敛输入框同步**（D4 修复）：`fillSwatches` 是所有配色变更后的唯一重绘点，把输入框同步放这里，保证「界面显示 A 色、输入框显示 A 色」恒成立。
3. **草稿归属读事实源而非 radio**：`change` 事件触发时 radio 已经翻页，此时读 radio 会把草稿写进另一个取值域（实测曾导致 `readBg` 被写成 `'#FFFFFF'`）。
4. **网格背景在阅读段禁用而非隐藏**：其 CSS 只作用于源码模式，隐藏会造成选项行重排；禁用 + tooltip「仅在源码模式生效」语义更清楚、布局不跳动。
