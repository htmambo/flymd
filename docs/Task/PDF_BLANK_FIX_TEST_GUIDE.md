## 修复内容

### 问题描述
PDF 导出功能生成的文件打开后内容为空白。

### 根本原因
`pdfContextExport.ts` 将容器定位到屏幕外（`left: -100000px`），但 `exportPdf()` 内部已处理离屏渲染。双重离屏导致 `getBoundingClientRect()` 返回零尺寸，html2canvas 无法捕获内容。

### 解决方案
将容器改为不可见但保留布局的定位方式：
- `position: absolute; left: 0; top: 0`
- `opacity: 0`（不可见）
- `pointer-events: none`（无交互）
- `z-index: -9999`（置于最底层）
- 添加 `requestAnimationFrame` 等待布局完成

### 修改文件
- `/home/hoping/htdocs/flymd/src/exporters/pdfContextExport.ts` (第 40-59 行)
